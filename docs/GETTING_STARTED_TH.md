# เริ่มทำ Garden Guardian แบบทีละขั้น

โปรเจกต์นี้เป็น “สมองส่วนมองเห็นและตัดสินใจ” ของหุ่นยนต์กำจัดวัชพืช
ตัวหุ่นที่วางไว้คือหุ่นเตี้ยทรงกลมที่ไถลไปบนพื้นเองแบบเครื่องดูดฝุ่น วิ่งอิสระบนสนามหญ้า
รุ่นปัจจุบันยังไม่ขยับมอเตอร์และไม่เปิดหัวตัดหรือหัวพ่น

## สิ่งที่ระบบจะเรียนรู้

เราสอนจากรูปจริงในสวน โดยตีกรอบพืชทุกต้นที่เห็น แล้วตั้งชื่อเป็น 2 กลุ่ม:

- พืชปลูก เช่น `tomato`, `basil`, `lettuce` — ระบบต้องปกป้อง
- วัชพืชเป้าหมาย เช่น `dandelion`, `crabgrass` — ระบบเสนอให้กำจัดได้เมื่อมั่นใจมากพอ

ชื่อทั้งสองกลุ่มแก้ได้ใน `data/data.yaml` และ `config/garden.yaml` แต่ชื่อในสองไฟล์
ต้องตรงกันทุกตัวอักษร ตัวอย่างวัชพืชในไฟล์เป็นเพียงตัวอย่าง ควรเปลี่ยนให้ตรงกับสวนจริง
ก่อนเริ่มตีกรอบรูป

## กฎตัดสินใจ

ผลลัพธ์มี 3 แบบ:

- `protect` (กรอบเขียว): เป็นพืชปลูก ห้ามแตะ
- `removal_candidate` (กรอบแดง): เป็นวัชพืชที่รู้จัก มั่นใจสูง และไม่อยู่ใกล้พืชปลูก
- `review` (กรอบเหลือง): ไม่แน่ใจ ไม่รู้จัก หรืออยู่ใกล้พืชปลูก ให้คนตรวจ

บริเวณที่ไม่มีกรอบไม่ได้แปลว่าเป็นวัชพืช แต่แปลว่า “ระบบไม่พบอะไร” จึงต้องไม่ทำงาน

## สิ่งที่ต้องเตรียมต่อไป

1. เลือกรายชื่อพืชปลูกและวัชพืชเป้าหมายจริง
2. ถ่ายรูปจากกล้องและความสูงใกล้เคียงกับที่จะติดบนหุ่นยนต์ หุ่นตัวนี้เตี้ยและอยู่ติดพื้น
   กล้องจึงมองเฉียงจากมุมต่ำ ไม่ใช่มองลงมาตรง ๆ จากด้านบน ควรถ่ายให้ตรงกับมุมนั้น
3. ถ่ายหลายเวลา หลายมุม หลายขนาด และให้มีทั้งดินแห้ง ดินเปียก และเงา
4. ตีกรอบพืชทุกต้นในภาพ ไม่เลือกตีเฉพาะต้นที่เห็นง่าย
5. แบ่งรูปเป็น train/valid/test แล้วเทรนโมเดล
6. รันแบบสังเกตการณ์และตรวจภาพทีละภาพก่อนคิดเรื่องกลไกกำจัด

อย่าใช้ภาพที่ถ่ายต่อเนื่องกันแทบเหมือนกันกระจายทั้งชุด train และ test เพราะคะแนนจะดูดี
เกินความจริง ควรแยกตามวันหรือแปลงปลูกแทน

## คำสั่งหลังมีชุดข้อมูลแล้ว

ตรวจชุดข้อมูล:

```bash
python src/utils.py
```

เทรน:

```bash
yolo detect train data=data/data.yaml model=yolov8n.pt epochs=100 imgsz=640
```

ตรวจรูปจริงโดยยังไม่สั่งฮาร์ดแวร์:

```bash
python src/detect.py --weights runs/detect/train/weights/best.pt --source path/to/photo.jpg
```

ดูรูปและไฟล์ `decisions.json` ใน `runs/observe/` ผลทุกชิ้นระบุ
`actuation_authorized: false` เพื่อย้ำว่านี่ยังเป็นเพียงคำแนะนำจากภาพ

## ก่อนเชื่อมกับหุ่นยนต์จริง

ยังต้องทำอย่างน้อย 5 เรื่อง:

1. แปลงพิกเซลในภาพเป็นระยะจริงบนพื้นเป็นเซนติเมตร (โครงอยู่ที่ `src/ground_plane.py`)
2. ทำให้หุ่นรู้ตำแหน่งตัวเองบนสนาม ซึ่งเป็นเรื่องที่ยังไม่มีคำตอบและยากที่สุดในตอนนี้
3. วัดระยะปลอดภัยตามขนาดจริงของหุ่นและหัวกำจัด
4. เพิ่มตัวควบคุมฮาร์ดแวร์ที่ปฏิเสธคำสั่งผิดปกติ
5. ติดปุ่มหยุดฉุกเฉินที่กดได้ทันทีบนตัวหุ่น

จนกว่าจะผ่านขั้นเหล่านี้ ควรใช้ระบบเพื่อวาดกรอบและเก็บผลเท่านั้น

ข้อควรระวังเพิ่มเติมสำหรับหุ่นที่เคลื่อนที่ได้: ตัวหุ่นขยับตลอดเวลา กรอบที่ตรวจได้จาก
ภาพหนึ่งจึงใช้ได้เฉพาะกับจังหวะที่ถ่ายภาพนั้น ถ้าหุ่นเลื่อนไปแล้วค่อยสั่งงาน ตำแหน่ง
จะไม่ตรงกับที่ตรวจไว้
